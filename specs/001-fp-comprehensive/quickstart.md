# Quickstart: 開発・実行手順

## 前提
- Node.js 22 LTS / npm

## セットアップ
```powershell
npm install
```

## 開発サーバー起動
```powershell
npm run dev
# 表示されたURL（既定 http://localhost:5173）をブラウザで開く
```

## テスト（計算コア）
```powershell
npm test          # 1回実行
npm run test:watch # 監視モード
```

## ビルド
```powershell
npm run build      # dist/ に出力
npm run preview    # ビルド結果をローカル確認
```

## 使い方（最短経路 / SC-001: 5分以内）
1. アプリ上部の免責表示を確認。
2. 「ライフプラン」タブで、本人の年齢・年収・年間支出・現在の貯蓄を入力。
3. 「サンプル入力」ボタンで例データを投入することも可能。
4. 年次キャッシュフロー表と資産推移グラフが即時表示され、資産が枯渇する年齢（あれば）が警告される。
5. 入力は自動的にブラウザ内（localStorage）に保存され、再読み込みで復元される。
6. 必要に応じて住宅ローン・積立・教育・年金・家計の各タブを利用。

## データの削除
- 設定/フッターの「全データ削除」で localStorage の保存内容を消去できる（FR-005）。

## プライバシー
- 入力データは外部に送信されず、利用者の端末内にのみ保存される（憲章II）。
