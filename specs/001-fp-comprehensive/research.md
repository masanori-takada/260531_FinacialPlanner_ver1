# Phase 0 Research: 技術選定と方針

## Decision 1: フロントエンドのみ・バックエンドなしのSPA

- **Decision**: React + TypeScript + Vite のSPAとし、サーバー/DBを持たない。
- **Rationale**: 憲章II（プライバシー優先・ローカルファースト）を構造的に満たす。個人金融データを
  端末外に出さないには、そもそもバックエンドを持たないのが最も確実。オフライン動作・配布の単純さも利点。
- **Alternatives considered**:
  - Next.js + サーバーDB: 認証・サーバー管理コストとデータ漏洩面が増え、憲章IIに反しやすい。却下。
  - デスクトップアプリ(Electron): 配布は容易だが重く、v1スコープには過剰。却下。

## Decision 2: 永続化は localStorage（バージョン付きスキーマ）

- **Decision**: 単一キー（例: `fp-app:v1`）にJSONで世帯・前提・各プランを保存。`schemaVersion`を持たせる。
- **Rationale**: 単一世帯・単一利用者前提（spec Assumptions）には十分。実装が単純でテスト容易。
- **Alternatives considered**: IndexedDB（大容量・非同期）は本規模には過剰。却下。

## Decision 3: 計算コアの分離（src/domain＝純粋関数）

- **Decision**: 全金融計算をUI非依存の純粋関数群に集約し、Vitestで単体テスト。
- **Rationale**: 憲章I/IV。UIなしでテスト可能・回帰検出が容易。税制改定時の差し替え点が局所化。
- **Alternatives considered**: UIコンポーネント内に計算を書く方式は検証困難で却下。

## Decision 4: 「検証可能な数式」と「政策定数」の分離（最重要方針）

- **Decision**:
  - 複利・積立将来価値、元利均等/元金均等の償還、繰上返済、キャッシュフロー投影は
    **時代不変の数式**として、ハンド計算の期待値で厳密にテストする。
  - 税率（譲渡益20.315%）・iDeCo所得控除帯・年金算定式の乗率・教育費の代表額・NISA枠は
    **改定されうる前提**として`src/domain/constants`に出典・適用年度コメント付きで隔離する。
    テストは「定数を所与として数式が正しいか」を確認し、「定数が現行法か」は確認しない。
- **Rationale**: SC-003（出典に基づく期待値と一致）を誠実に満たす。法改定で陳腐化する数値を
  テストで「正解」と固定すると、accuracy theater（正確性の見せかけ）になるため避ける。
- **Alternatives considered**: 全数値を外部APIで取得 → 憲章II（外部送信）に反し却下。

## Decision 5: 可視化は Recharts

- **Decision**: 資産推移の折れ線、教育費・収支の棒グラフ等にRechartsを用いる。
- **Rationale**: Reactネイティブで宣言的、軽量、学習コスト低。
- **Alternatives considered**: Chart.js（命令的でReact統合にラッパ要）、D3（低水準すぎ）。却下。

## 採用する代表値・算定式（前提・出典メモ）

> いずれも「概算用の代表値・簡略式」。適用年度・出典はコード定数のコメントに明記する。
> 正式な個別試算には用いない（spec FR-004 / Assumptions）。

- **上場株式等の譲渡益・配当課税**: 20.315%（所得税15% + 復興特別所得税0.315% + 住民税5%）。
- **NISA**: 運用益・配当が非課税（生涯非課税保有限度額1,800万円・年間投資枠等は概算注記）。
- **iDeCo**: 掛金が全額所得控除（小規模企業共済等掛金控除）。受取時課税は概算注記。
  節税概算＝年間掛金 × （所得税率 + 住民税率10%）。所得税率は課税所得帯から選択。
- **老齢基礎年金**: 満額（40年=480月納付）を定数化し、納付月数で按分。
- **老齢厚生年金（概算）**: 平均標準報酬額 × 乗率(約5.481/1000) × 加入月数、の簡略式。
- **繰上げ/繰下げ**: 繰上げは1月あたり0.4%減（60歳まで最大-24%）、繰下げは1月あたり0.7%増
  （75歳まで最大+84%）。
- **教育費**: 文科省「子供の学習費調査」等を典拠とした進路別（公立/私立、文系/理系、自宅/下宿）の
  年額代表値テーブルを定数化。
