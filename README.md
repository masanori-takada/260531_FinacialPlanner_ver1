# FPプランナー

日本版の包括的ファイナンシャルプランナー支援アプリです。ブラウザ内で動くフロントエンドのみのSPAで、入力データはこの端末のlocalStorageにのみ保存されます。

## 主な機能

- ライフプラン / キャッシュフロー表: 生涯収支投影、資産推移、資産枯渇警告
- 積立シミュレーション: NISA / iDeCo / 特定口座の比較、iDeCo節税概算
- 住宅ローン: 元利均等・元金均等、償還表、繰上返済効果
- 教育資金: 進路別の年次費用と総額
- 公的年金: 老齢基礎年金・厚生年金の概算、繰上げ・繰下げ調整
- 家計管理: 月次収支、貯蓄率、カテゴリ別集計

## 起動方法

```bash
npm install
npm run dev
```

開発サーバー起動後、表示されたURL（通常は `http://localhost:5173`）をブラウザで開きます。

## 検証

```bash
npm test
npm run build
```

## プライバシー

本アプリはバックエンドを持たず、個人データを外部に送信しません。入力内容はブラウザのlocalStorageに保存され、ヘッダーの「全データ削除」から削除できます。

## 免責

本アプリの計算結果は、入力値とアプリ内の前提定数に基づく概算です。税制、社会保険、教育費、金融商品の条件は変更される可能性があります。正式な判断や個別の助言が必要な場合は、税理士、社会保険労務士、ファイナンシャルプランナーなどの専門家に相談してください。
